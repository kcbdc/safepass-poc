# SafePass v1.7.6 — 관리자 대여처 접근 키 초기화

## 교체 파일
- `web/main.js`만 교체합니다. Worker는 v1.7.5 유지. 기존 Worker에 `/api/admin/partner/rotate-key` 엔드포인트가 이미 구현되어 있습니다.
- D1 마이그레이션은 없습니다.

## 동작
1. 대여자 모드 → 통합관리, 관리자 인증 완료.
2. 대여처 현황·중지 관리 → 해당 대여처의 `접근 키 초기화` 클릭 → 재발급 확인.
3. 새 64자리 접근 키는 한 번만 표시되며, 복사 가능합니다. Worker는 `partners.key_hash`만 갱신하고 이전 키를 즉시 무효화하며 `PARTNER_KEY_ROTATED` 감사기록을 남깁니다.
4. 현재 브라우저 세션에 대상 대여처 ID와 새 키를 자동 적용합니다. `해당 대여처 목록 열기` 클릭 시 대여자 홈의 대여 목록을 다시 조회합니다.
5. 기존 `rental_requests`와 `guarantee_tokens`는 변경하지 않아 거래 기록이 유지됩니다.

## 주의사항
- 기존 키 원문은 해시로부터 복원하지 않으며, 키를 다시 잃어버리면 재발급이 필요합니다.
- 다른 브라우저/직원 기기의 이전 키는 폐기되므로 새 키를 안전하게 전달해야 합니다.
- 중지·거절 상태의 대여처는 키를 갱신해도 자동으로 활성화되지 않습니다. 관리자 재개가 필요합니다.
- 목록 새로고침 후 새 접근 키를 재출력할 수 없습니다. 발급 직후 복사하세요.
- 서버의 관리자 인증(`ADMIN_KEY`)이 유효해야만 키 초기화가 가능합니다.
