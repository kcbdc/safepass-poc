# SafePass v1.5.8 품목별 이용한도 패치

적용 파일: `web/main.js`, `worker/src/index.ts` (기존 v1.5.7 웹 + v1.5.6 Worker를 기반으로 병합)

정책 (모두 PoC·기기 식별 기반):
- 자전거: 동일 기기(이용자 가명 해시)에서 반납되지 않은 자전거가 있으면 추가 발급 불가. 최대 3시간.
- 면접정장: 최대 96시간(4일), 동일 기기에서 UTC 달력연도 기준 발급 3회까지. 반납 건과 20초 시연 발급도 횟수에 포함.
- 캠핑장비: 최대 336시간(14일).
- 유모차: 24시간, 생활공구: 72시간, 한복: 48시간(기존 정책 유지).
- 20초 시연 선택지는 유지합니다. 자전거의 동시 대여 제한과 면접정장의 횟수 제한을 우회하지 않습니다.
- 정책 위반 대여기간은 `/api/request/create`에서 거절합니다. 품목별 이용자 대여 건수는 이용자 인증 시점인 `/api/token/issue`에서 서버가 검사하고, 발급 상태 UPDATE의 조건절로 최종 차단합니다.
- 사용자는 오류 문구를 화면에서 확인할 수 있습니다.

주의: 이 앱은 실제 주민 신원확인이 아닌 모의 기기 식별 기반입니다. 기기 변경·브라우저 데이터 삭제 시 이용한도를 회피할 수 있어 실제 서비스용 인적 동일성 보장과는 다릅니다. 기간·횟수는 실제 기관 규정과 별개이며, 추가 약관·공식 인증 연계가 필요합니다.

배포: `worker/src/index.ts` Worker 배포 → `web/main.js` Pages 배포. 기존 D1 테이블·기존 기록은 유지, 별도 마이그레이션 없음.

스테이징 확인:
1. 자전거 3시간 발급 성공, 반납 없이 같은 브라우저 다른 자전거 QR 발급 시 409 차단. 기존 대여 RETURNED 후 새 자전거 발급 성공.
2. 자전거 24시간 QR 생성 시 409 거부.
3. 면접정장 96시간 발급 3회 성공, 4회 거부. 반납 후에도 4회 거부.
4. 캠핑장비 336시간 발급 성공, 336시간 초과는 생성 단계에서 차단.
5. 사용자 화면의 오류 안내 및 20초 시연 정상 동작 검증.

본 작업환경은 실제 Cloudflare D1 및 모바일 브라우저에 접속해 통합시험을 수행하지 못했으며, 정적 코드 검사를 실시했습니다.
