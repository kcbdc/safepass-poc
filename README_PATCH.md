# SafePass v1.5.3 — 보증기간 일치 수정

웹과 Worker를 **모두** 교체해야 합니다. D1 마이그레이션은 불필요합니다.

- `web/main.js`: 6종 모두 20초, 3, 24, 48, 72, 96, 168시간 선택 가능. 기본값 24시간.
- `worker/src/index.ts`: 동일한 기간을 허용하고, 미승인 대여처와 유효하지 않은 품목/기간 에러를 구분.
- 품목별 실제 지자체 정책은 정보용으로 남기고, PoC 시연용 보증기간에는 적용하지 않습니다.
- QR 요청 코드의 발급 유효시간과 대여 보증기간은 서로 다릅니다.

적용 순서: (1) Worker 배포 (2) Pages의 웹 파일 배포 (3) 모바일/PC 새로고침 (4) 각 품목별 24, 48, 72시간 요청 생성 확인.

정적 검사 완료. Cloudflare 실제 통합 테스트 및 실제 대여처 인증 데이터 확인은 수행하지 않았습니다.
