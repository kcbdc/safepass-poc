# SafePass v1.7.5 — 2차 보호 키 진단 및 새로고침 화면 복원

## 반영 파일
- web/main.js: 기존 탭/메뉴 복원, 대여자 화면으로 복귀 시 비밀번호 재확인, 검토자 키 오류 구분
- worker/src/index.ts: 검토자 키 누락·관리자 인증 누락·검토자 키 불일치를 구분해 오류 출력, /health 버전 1.7.5

## 중요한 인증 원칙
1. 2차 보호 키는 **Worker의 REVIEWER_KEY Secret**과 일치해야 합니다. 관리자 ADMIN_KEY와는 **다른 값**으로 설정하세요.
2. `2단계 보호 키 확인`은 관리자 권한과 2차 키를 모두 검증합니다. 올바른 2차 키라도 관리자 인증이 안 되어 있으면 실패합니다.
3. 새로고침 시 이용자 홈으로 돌아가지 않고 탭/메뉴를 복원합니다. 대여자 진입 비밀번호와 2차 보호 키는 다시 입력해야 하며 브라우저에 저장하지 않습니다.
4. 관리자 인증은 기존 구현대로 탭 세션에서 복구됩니다. 2차 검토자 키는 새로고침 시 초기화됩니다.

## 배포
1. Worker 먼저 `worker/src/index.ts` 업데이트 후 배포
2. Cloudflare Worker의 REVIEWER_KEY, ADMIN_KEY, PARTNER_ENTRY_PASSWORD Secret이 모두 올바른지 확인
3. Pages에 `web/main.js` 적용 후 배포
4. /health에서 version 1.7.5 확인

## 확인 테스트
- 관리자 인증 상태에서 유효한 REVIEWER_KEY를 입력 → 확인 완료
- 일부러 틀린 키 입력 → '2단계 보호 키가 일치하지 않습니다' 안내
- 새로고침 → 기존 대여자/통합관리 페이지 유지, 대여자 비밀번호 재인증 후 같은 메뉴 복귀
- 보호 키 확인 후 2차 승인 및 가상 신원 조회는 별도로 테스트 필요
