# SafePass v1.2 — 독립형 모바일신분증 대여 보증 모의 PoC

실제 모바일신분증 인증·금전 손해배상 보증·법적 신원정보 제공 서비스가 **아닙니다**. K Wallet 원본과 DB는 사용하거나 수정하지 않습니다.

## 포함 기능
- 이용자: 6종 대여 품목, QR 카메라/사진 인식, 요청 확인, **시험용 모의 PIN**, 서버에 동의 버전/시각 저장, 토큰 발급, 다건 보증/열람 이력, STANDBY 표시, 반납 후 REVOKED
- 대여자: APPROVED 등록/접근 키, 요청 생성/검증/반납, 20초 만료 시연, 미반납 조회
- 관리자: 심사 승인 후에만 허용되는 **허구의 가상 신원** 열람, 열람 감사 기록, 키 재발급/폐기 API, 발급·반납 처리시간 API, 시험용 독촉 알림, 비교시험 스톱워치/CSV/큰 글씨
- 보호장치: 등록 시간당 3건, 대여처 요청 시간당 60건 제한(단일 D1 기록 방식), 관리자 키 상수시간 비교, 6종 모의 품목 정책

## 적용 전 필수 사항
1. **DB 백업과 스테이징 복제**를 먼저 수행하세요. 기존 DB를 새로 만들거나 삭제하지 마세요.
2. 현재 실제 운영 DB의 테이블/컬럼을 확인하세요. 기존 ZIP마다 마이그레이션의 모습이 달라 `0001_init.sql`은 **새 DB용**이고 이미 운영 중인 DB에는 다시 적용하면 안 됩니다.
3. 현재 DB에 `rental_requests.demo_holder`, `demo_consents`, `demo_notices`, `request_limits`가 없으면 `migrations/0002_hardening.sql`을 **한 번만** 적용하세요. 이미 존재하면 재실행하지 마세요. `PRAGMA table_info(rental_requests);` 등으로 먼저 확인하세요.
4. `worker/src/index.ts`를 Workers에 배포한 다음 `ALLOWED_ORIGIN`, `TOKEN_SECRET`, `ADMIN_KEY`, `DB`를 확인하세요. Pages `SAFEPASS_API` 서비스 바인딩은 기존 방식 그대로 유지합니다.
5. Pages `web/main.js`, `web/style.css`를 함께 배포하세요. 일부만 업데이트하면 동의 버전 오류가 납니다.
6. `node tests/smoke.mjs https://safepass-poc.pages.dev`로 비파괴 기본 테스트를 실행하세요. T09~T13은 전용 DB의 실제 시나리오에서 수동 또는 전용 테스트로 검증해야 합니다.

## 지원되는 정책 (시연용, 지역 운영기준 아님)
| 품목 | 최대 대여 시간 | 비고 |
|---|---:|---|
| 자전거 | 3시간 | 한 사람당 1대 예시; **현재 서버에서 1대 동시 대여 강제는 미구현** |
| 유모차 | 24시간 | 시연 예시 |

| 생활공구 | 72시간 | 3일 |
| 면접정장 | 96시간 | 연 3회 참고. 시험용 `demo_holder`가 제공될 때만 서버 카운트. **실제 신원 기반 제한 아님** |

모든 품목은 기존 20초 특수 시연 기간을 허용합니다. 위 정책은 여러 지자체의 서로 다른 운영규정을 대변하지 않습니다.

## 보안 범위와 미구현 사항
- `X-Demo-Device`는 브라우저 저장 UUID이므로 실제 신원인증/소유권 증명이 아닙니다.
- D1 요청 제한은 분산 환경에서 원자적이지 않으므로 강력한 봇 방어나 WAF를 대체하지 않습니다.
- 미반납 사례의 이름·연락처는 모두 허구 프로필입니다. 실명·주민번호·실제 PIN 입력 금지.
- 가상 신원 조회 감사 로그 해시 체인, 예약 자동파기, 실제 Web Push, 실제 모바일신분증 연계, 기관별 PKI 인증, QR 라이브러리 완전 자체 호스팅은 **아직 미구현**입니다.
- 시험을 실행하지 않았는데 통과했다고 기획서에 기재하지 마세요.

## 자동/수동 검증
`tests/smoke.mjs`는 읽기 및 미인증 거절 여부 중심의 **T01~T08만 실행**하고, 쓰기와 상태 변화가 필요한 T09~T13은 별도 전용 DB에서 검증하도록 의도적으로 NOT_RUN 처리합니다. 실제 통과 결과는 실행 환경과 날짜를 포함해 기록하세요.
