# SafePass v1.7.3 — 기존 승인 기록의 2단계 심사 복구

## 증상과 원인
기존 버전에서 생성된 `APPROVED_FOR_REVIEW` 상태의 심사 기록은 독립 2차 승인 감사기록이 없는 경우가 있습니다. 최신 Worker는 해당 기록의 신원정보 열람을 거부하는데, 관리화면은 상태만 보고 열람 버튼을 노출하던 문제를 수정했습니다.

## 수정 사항
- 관리자 심사 목록과 미반납 조회 API에서 독립 2차 승인 감사기록 존재 여부 반환
- 기존 단독 승인 건은 `기존 승인 1차 재확인` 버튼 표시
- 재확인 후 `PENDING_SECOND_APPROVAL` 전환, 별도 검토자 키로 2차 승인 후 가상 신원정보 확인
- 2차 승인된 건만 가상 신원정보 버튼 표시
- 기존 감사기록은 보존하고, 실제 신원정보가 아닌 합성 시험 데이터만 표시

## Cloudflare 적용
1. `worker/src/index.ts`를 Worker에 배포
2. `web/main.js`를 Pages에 배포
3. Worker Secret `REVIEWER_KEY`가 `ADMIN_KEY`와 다른 값인지 확인
4. 통합관리에서 관리자 1차 재확인 → 독립 검토자 2차 승인 → 가상 신원 확인 순으로 시험

`/health` 응답 `version: 1.7.3` 확인. D1 마이그레이션 불필요.

## 제한
코드 구문 검사 및 패키지 무결성 검사는 수행했지만 실제 Cloudflare/D1에서의 배포 통합시험은 별도로 필요합니다. 반드시 모의 시험 데이터만 이용하세요.
