# SafePass v1.7.7 — 심사 시연 대여처 인증 복구

## 원인
심사위원 원클릭 대여처는 기존 Worker에서 `partners.created_at` 기준 60분 후 접근이 차단됩니다. 기존 ‘접근 키 초기화’ API는 해시만 변경해 만료 시간이 갱신되지 않아, 초기화 직후에도 ‘대여 현황 조회 불가’ 오류가 지속될 수 있었습니다. 다른 대여처로 변경하면서 오래된 키가 브라우저에 남은 경우에도 유사한 인증 오류가 발생합니다.

## 수정
- 관리자 인증 후 심사 시연용 대여처의 **접근 키 초기화** 실행 시 새 접근 키 발급과 60분 유효기간 갱신을 함께 수행합니다.
- 기존 `rental_requests`, `guarantee_tokens` 데이터는 변경하지 않습니다. 대여처 ID도 유지됩니다.
- 대여 현황 조회 시 실제 키가 일치하는 심사 대여처의 60분 만료를 별도 문구로 표시합니다.
- 일반 대여처의 접근 키 초기화 동작과 관리자 중지·거절 권한 차단은 변경하지 않습니다.
- 이전 키는 즉시 폐기됩니다. 새 키를 발급 직후 복사하세요.

## 배포
1. `worker/src/index.ts`를 Worker에 배포하세요.
2. `web/main.js`를 Cloudflare Pages에 배포하세요.
3. `/health`에서 `version: 1.7.7`을 확인하세요.
4. 대여자 화면 → 통합관리 → 관리자 인증 → 대여처 현황·중지 관리에서 해당 `demo-...` 대여처의 **접근 키 초기화**를 누릅니다.
5. **해당 대여처 목록 열기**를 눌러 새 접근 키로 기존 대여 목록을 확인합니다.

## 유의사항
- 심사 시연 대여처 60분 정책은 유지됩니다. 필요할 때마다 관리자 키 초기화로 갱신합니다.
- `PARTNER_ENTRY_PASSWORD`, `ADMIN_KEY`, `REVIEWER_KEY`, `DEMO_TOOLS_ENABLED`, D1 바인딩은 기존 설정을 유지합니다.
- 실제 Cloudflare D1 연동은 배포 후 검증해야 합니다.
