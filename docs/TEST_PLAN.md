# 시험 시나리오 및 검수 기준

| 번호 | 시험 | 기대 결과 |
|---|---|---|
| T01 | 대여처가 요청 생성 | SP1 코드 및 대여 건 ID 생성 |
| T02 | 유효 요청 조회 | 품목/기간만 반환 |
| T03 | 모의 PIN 틀림 | 401 차단 |
| T04 | 1234 입력 후 발급 | ACTIVE 1건 생성 |
| T05 | 동일 요청으로 재발급 | 409 차단 |
| T06 | 보증 검증 | valid=true, 신원정보 미포함 |
| T07 | 반납 완료 | RETURNED, 토큰 REVOKED |
| T08 | 반납 후 재검증 | valid=false |
| T09 | 기한 전 예외 열람 신청 | 409 거절 |
| T10 | 관리자 키 부재 또는 오류 | 401 거절 |
| T11 | 관리 키로 조회 | 감사 내역 조회 |
| T12 | QR 코드 변조 | 400 거절 |
| T13 | 다른 Origin에서 요청 | 403 거절 (Origin 헤더 있을 때) |

**테스트 미수행 상태**: 위 항목은 계획이며 실측 통과 결과가 아닙니다.

## 프로덕션 전 필수 과제
대여처 인증/권한 통제, 로그인, 개인정보 처리 영향 검토, 소비자 통지, 기기 인증/WebAuthn, 트랜잭션 원자성 검증, 재시도·동시성 검증, rate limiting, 실제 공식 모바일신분증 연계 가능 범위 확인, QR 스캔 및 QR 만료 정책, 데이터 보존/삭제 정책, 독립 보안검토.
