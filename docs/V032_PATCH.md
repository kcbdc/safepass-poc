# SafePass v0.3.2 — 대여 요청 버튼 진단 및 수정

- 대여 요청 생성 시 화면에 요청 중·성공·실패 상태를 계속 표시합니다.
- 대여처 접근 키 입력 후 별도의 '접근 키 적용' 클릭 없이 생성 요청에 최신 키를 사용합니다.
- 등록 요청 `/api/partner/register`에서 기존 접근 키 헤더가 잘못 전달되던 경로 오타를 바로잡았습니다.
- API 네트워크 오류는 Worker URL 및 CORS 점검 안내로 표시합니다.

## 업데이트
GitHub 저장소 `web/main.js`만 새 파일로 교체해 Commit합니다. Cloudflare Pages의 새 배포가 Ready 상태가 된 후 강력 새로고침하세요. Worker·D1을 수정할 필요는 없습니다.

## 사용 전제
등록한 대여처가 관리자 화면에서 APPROVED 상태여야 합니다. 대여처 ID와 등록 시 발급된 64자리 접근 키가 일치해야 합니다. `/health`가 JSON을 반환하는지 반드시 별도로 확인하세요.

주의: 이 패치는 코드 정적 검사까지 진행했으며 사용자 Cloudflare 환경에서 실제 연동 시험한 것은 아닙니다.
