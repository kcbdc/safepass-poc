# SafePass v1.7.4 — 관리자 목록/2단계 보호/대여자 진입

## 반영 파일
- web/main.js
- web/style.css
- worker/src/index.ts

## 반드시 추가할 Cloudflare Worker Secret
- PARTNER_ENTRY_PASSWORD : 대여자 모드 진입 전용 비밀번호. ADMIN_KEY/REVIEWER_KEY와 다른 값 권장.
- 기존 ADMIN_KEY와 REVIEWER_KEY는 그대로 유지하고 서로 다른 값을 사용합니다.
- 대시보드에서 추가한 Secret이 배포 후 사라지는 설정인지 확인하십시오. 키는 저장소에 넣지 마십시오.

## 변경사항
1. 이용자 화면에서 대여자 모드 진입 시 비밀번호를 서버에서 검증합니다. 브라우저 새로고침 시 재입력합니다.
2. 통합관리의 대여 건 ID, 대여처 현황 및 중지, 미반납 신원정보 2단계 심사는 각각 기본 5건만 표시하고 5건씩 펼칩니다. API 조회 상한 100건은 유지합니다.
3. 관리자는 대여처 ID를 조회할 수 있으며, 현 브라우저 세션에 적용된 해당 대여처 키만 끝 4글자 마스킹 표시합니다. 이전 키 원문은 서버에 SHA-256 해시로 저장되므로 복원/재조회할 수 없습니다. 실제 원문이 필요한 경우 키 재발급(기존 키 폐기)을 사용합니다.
4. 통합관리의 2차 검토자 키 입력 뒤 '2단계 보호 키 확인' 버튼을 눌러 서버 인증합니다. 키가 없거나 검증 전 2차 승인을 누르면 알림을 표시합니다.
5. 기존 승인 기록은 1차 재확인→독립 2차 승인→가상 신원정보 열람을 거칩니다. 미반납/만료 및 두 승인 기록을 검사하며 이를 우회하지 않습니다.

## 배포 순서
Worker 배포 → /health 에서 version=1.7.4 확인 → PARTNER_ENTRY_PASSWORD·REVIEWER_KEY 등 Secret 설정 확인 → Pages 배포 → 강력 새로고침.

## 주의
대여자 모드의 비밀번호는 데모 UI 진입 게이트이며, 각 대여 거래 API의 대여처별 접근 키 검증을 대체하지 않습니다.
실제 모바일신분증이나 실제 개인정보를 사용하지 않는 시험용 PoC입니다.
JS 구문 검사 통과. Worker 타입 선언(D1Database)을 제외한 TypeScript 구문상 오류 없음. 라이브 Worker/D1 연동은 미실행.
